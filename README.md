# 提亚兰 · Tiaran

一个 2D 俯视角多人在线 RPG 的 MVP。塞尔达式的原创世界观：守望者从长眠中醒来，
集齐风之刃碎片，点亮三座守望塔，最后全服联手讨伐蚀王卡兰索的影身。

## 跑起来

```bash
npm install
npm start          # 默认 http://localhost:3000
```

多开几个浏览器标签就是多人联机。局域网内别人访问 `http://你的IP:3000` 即可加入同一个世界。

## 操作

| 键 | 作用 |
|---|---|
| WASD / 方向键 | 移动 |
| J / 空格 / 鼠标左键 | 攻击 |
| E | 与 NPC、守望塔交互 |
| B | 背包（点击物品使用 / 装备） |
| Q | 收起或展开任务面板 |
| Enter | 聊天 |

## 主线

1. **苔原苏醒** — 守林长老 · 奥兰：清理 5 只腐蚀野豚，奖励锈剑
2. **铁匠的活计** — 铁匠 · 图恩：交 3 张腐蚀兽皮换皮甲
3. **风之刃碎片** — 击杀影狼首领（精英怪），推进全服第二章
4. **点亮守望塔** — 带碎片走到三座塔前按 E，推进全服第三章
5. **王座之门** — 蚀王影身降临地图中央，2000 血，一个人打不动

第 3、4、5 步会改变**全服共享**的章节进度并触发世界公告，这是 MVP 里最"MMO"的部分。

## 架构

服务端权威。客户端只发送输入意图，位置、战斗、掉落全部由服务端裁决，
客户端做本地预测让移动跟手，收到快照后平滑对账。

```
server/
  data.js     世界观与全部数值配置（怪物、物品、任务、NPC、刷新点）
  world.js    固定种子地图生成 + 碰撞检测
  game.js     世界状态、主循环（20Hz）、玩家/交互/快照
  combat.js   伤害计算、攻击判定、怪物 AI、掉落
  quests.js   任务接取、进度、交付
  index.js    HTTP 静态服务 + WebSocket 路由
public/
  game.js     Canvas 渲染、输入、本地预测、UI
```

网络协议是纯 JSON，字段名压到 1-2 个字符。每 tick 只把玩家视野
700px 内的实体发给他，人多了也不会撑爆带宽。
